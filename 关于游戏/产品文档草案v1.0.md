《宫爆老奶奶：万物生》游戏产品文档（GDD 草案 v0.1）
一、产品概述
产品名：宫爆老奶奶：万物生
类型：单局制肉鸽 · 生存走位 · 培育策略
平台：移动端（竖屏单手操作）
核心一句话：走位捡种子，即时炸场解围，培育植物推线，在死气侵蚀中让土地活过来。

设计目标：

保留《宫爆老奶奶》"走位—捡取—触发"的操作骨架与即时爽感。

用"农耕生长"主题重构决策逻辑，把技能球变成种子，把释放变成培育。

用"即时型种子 + 培育型种子"双轨系统平衡爽感与深度。

目标用户：原《宫爆老奶奶》老玩家（情怀+手感熟悉）、轻度肉鸽玩家、喜欢"种田+割草"混搭的休闲玩家。

二、核心玩法循环
单局循环：
死气从边缘向内收缩 → 玩家走位躲避 → 捡取掉落种子 → 即时型种子解围 / 培育型种子找位置种下 → 守护生长 → 植物持续输出推线 → 死气再压上 → 循环至存活达标或土地全被侵蚀。

局外循环：单局结算获得"灵韵" → 解锁新种子种类、新伴生生灵、新老奶奶皮肤/被动 → 下一局尝试新构筑。

核心张力：好东西（灵种、高价值种子）刷在死气边缘，想拿就得冒险；培育型种子种在死气上效果翻倍但可能被吞噬；即时型种子能救命但不产生持续收益。

三、双轨种子系统（核心系统）
3.1 即时型种子——解围锚点
属性	设计
触发	捡到后一键种下，0.5 秒内生效
持续	1–2 秒后消失，不留场
定位	应急清场、创造安全窗口，不负责推图
限制	伤害有上限（清普通死气团，对精英只击退）；场上同时只存在 1 个即时效果；短冷却防连扔
隐性成本	不产生持续收益，炸完即无
初始三种：

爆裂瓜：种下即炸，范围击退 + 中等伤害，清出一片安全区。

冰晶荚：炸开一圈冰雾，冻结周围死气 1.5 秒，给培育窗口。

荆棘弹：向四周弹射尖刺，清近身小型死气团，打不动大型。

3.2 培育型种子——推线与深度
属性	设计
触发	捡到后选择位置种下，延迟 2–3 秒生长
持续	成型后长期驻场，持续输出/辅助
定位	推进战线、保护土地、连锁生长
风险	种在死气侵蚀区效果翻倍，但生长期间需玩家在附近"守护"几秒，失败则种子被吞噬
收益	成型植物持续生效，可连锁（A 植物抑制 B，C 植物调和）
初始三种：

冰霜草丛：成型后持续减速一片区域的死气。

喷瓜藤：成型后自动射击附近枯败源。

护土根须：成型后形成一圈临时屏障，延缓死气侵蚀该片土地。

3.3 双轨节奏
死气压上 → 即时种子解围 → 趁空档在边缘种培育种子 → 守护几秒 → 植物成型持续输出 → 死气再压上 → 循环

即时种子负责"活下来"，培育种子负责"推出去"。操作密度有起伏，快慢交替。

四、压力系统：死气侵蚀
死气从地图边缘持续向内收缩，覆盖已复苏土地。

老奶奶走过的地面短暂复苏，但会被死气重新侵蚀。

死气浓度分区域：边缘浓、中心淡；浓区种培育种子效果翻倍但风险高。

精英死气团：移动慢、血厚，即时种子只能击退，必须靠成型植物消灭。

胜负条件：存活 3 分钟即胜利；死气覆盖全部土地则失败。

五、伴生生灵系统（对应原版宠物）
由植物/土地孕育的精灵，跟随老奶奶自动攻击或辅助。局内通过培育特定植物组合概率孕育，或局外解锁携带。初始设计 2–3 只，如：

土灵：自动拾取附近种子。

萤火：照亮死气浓区，短暂显示灵种位置。

六、局外成长
灵韵：单局结算货币，用于解锁新种子、新伴生生灵、老奶奶被动。

图鉴：收集植物种类，解锁背景故事（呼应"万物生"农耕文明意象）。

难度阶梯：随局数提升死气收缩速度与精英密度。

七、操作与界面（竖屏单手）
移动：虚拟摇杆（放弃原版重力感应，降低门槛）。

拾取：靠近自动拾取，或按键拾取（可设置）。

种植：捡到种子后，点击地面种下；即时型一键即种，培育型可拖拽选位。

守护：培育型种下后，玩家在半径内自动进入守护状态，有进度条。

UI：顶部存活计时与死气覆盖百分比；底部种子槽（最多 3 格）；种子槽旁显示即时/培育标识。

八、最小可玩原型（MVP）范围
第一版只做：

1 张方形地图，死气从边缘收缩。

老奶奶移动 + 自动拾取。

即时型种子 1 种（爆裂瓜）+ 培育型种子 1 种（喷瓜藤）。

死气普通团 1 种 + 精英团 1 种。

存活 3 分钟胜利 / 土地全覆盖失败。

无局外成长、无伴生生灵、无图鉴。

验证目标：即时种子的"解围够不够爽"、培育种子的"等待+守护是否可接受"、双轨节奏是否成立。手感对了再扩种类与局外系统。

九、风险与对策
风险	对策
培育节奏拖慢爽感	即时型种子保底爽感；培育植物持续生效可边种边走，非站桩等
即时型种子变成唯一解	伤害上限 + 不产生持续收益 + 精英只击退，逼玩家碰培育线
双轨并行导致认知过载	MVP 只各做 1 种，UI 明确区分即时/培育标识
主题融合流于换皮	决策逻辑必须变（位置、守护、风险翻倍），不能只是种子=技能球
