一、项目基本信息
项	内容
项目名	gongbao-wanwusheng
类型	单局制肉鸽 · 生存走位 · 培育策略
平台	移动端竖屏（优先 Web/H5 原型，后续可包壳）
引擎/技术栈	Phaser 3 + TypeScript + Vite（H5 优先，便于快速验证与跨端）
美术	首版用占位图形（色块/几何体+简单粒子），不阻塞逻辑开发

选型理由：Phaser 3 对 2D 走位、碰撞、粒子、对象池支持成熟，TypeScript 便于 AI 生成结构化代码，Vite 启动快、H5 可直接在手机浏览器测试竖屏手感。若后续要上原生，可迁移至 Cocos 或包壳。

六、核心模块伪代码
6.1 InputSystem（虚拟摇杆）
text
onPointerDown: 记录摇杆中心
onPointerMove: 计算方向向量，归一化，输出 moveVec
onPointerUp: moveVec = 0
Player.update: position += moveVec * speed * dt
6.2 SeedSystem（掉落/拾取/槽位）
text
每 SEED_DROP_INTERVAL 随机时刻:
在死气边缘附近随机点生成 Seed（kind 随机 instant/grow）
掉落点 60% 概率落在死气覆盖区（制造风险收益）

Player 与 Seed 碰撞:
if 种子槽未满: 拾取入槽
else: 不拾取（提示槽满）

槽位点击/拖拽:
即时型: 点击即种在当前玩家位置附近
培育型: 拖拽选位后种下
种下后清空该槽
6.3 PlantingSystem（种植/守护/生长）
text
种下培育型:
创建 GrowPlant(state='growing', growTimer=growTime)
每帧检查: 玩家是否在 guardRadius 内
if 在: growTimer -= dt; 显示守护进度
if 不在: growTimer 暂停（或缓慢回退，首版用暂停）
growTimer<=0: state='mature'，开始攻击

种下即时型:
创建 InstantSeed，0.1s 后触发爆炸:
范围内 MiasmaUnit: 扣 damage，施加击退
创建粒子占位特效，1.5s 后销毁
设置全局 instantCooldown
6.4 MiasmaSystem（收缩与侵蚀）
text
MiasmaField:
维护一个不断内缩的矩形边界（四边同时收缩）
每帧 shrinkSpeed*dt 内缩
绘制半透明遮罩表示死气区
玩家在死气区内: 每秒扣 damagePerSecond

MiasmaUnit 生成:
在死气区内随机点生成，向玩家缓慢移动
接触玩家: 造成伤害 + 玩家进入短无敌
被即时种子击退后 0.5s 内不再推进
被植物/玩家伤害击杀
6.5 WinLoseSystem
text
每帧检查:
if 存活时间 >= WIN_TIME: 胜利 → ResultScene
if 死气覆盖矩形面积 >= 全图面积: 失败 → ResultScene
if 玩家 hp <= 0: 失败 → ResultScene
6.6 HUD
text
顶部: 存活计时（倒计时 180s）、死气覆盖百分比
底部: 3 个种子槽（显示 kind 颜色与图标占位）
中央: 守护进度条（培育型生长时显示）

十、风险与调优重点
风险	调优手段（改 gameConfig 即可）
即时种子不够爽	提高 damage/knockback/radius，缩短 cooldown
即时种子过强成唯一解	降伤害、精英免疫击退、加长冷却
培育等待太拖	缩短 growTime、放大 guardRadius、允许边种边走
死气压力过大/过小	调 shrinkSpeed、damagePerSecond、刷怪间隔
手机卡顿	对象池、限制同屏死气团数量、粒子降级
