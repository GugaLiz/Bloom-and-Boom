# 万物生 · Bloom & Boom

竖屏 H5 自动战斗原型。参考提供的《宫爆老奶奶》操作与成长流程，融合种子武器、植物炮台和土地复苏。

## 启动与检查

使用 Node.js 22.12+：

```sh
npm install
npm run dev
```

Windows 默认 Node 过旧、但 PATH 中有其他现代版本时，可运行 `.\scripts\dev.ps1`。此脚本只在当前进程选版本，不修改系统默认设置。

终端会显示 Local 与 Network 地址。手机和电脑在同一局域网时使用 Network 地址。

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run preview
```

## 在线试玩与部署

试玩地址：[万物生 · Bloom & Boom](https://gugaliz.github.io/Bloom-and-Boom/)。

推送到 `main` 分支后，GitHub Actions 会自动安装依赖、运行单元测试、构建并发布到 GitHub Pages。也可以在仓库的 Actions 页面手动运行 `Deploy to GitHub Pages`。仓库 Settings → Pages 的发布来源需设置为 GitHub Actions。

Vite 使用相对资源路径，支持 GitHub Pages 的项目子目录。构建产物由工作流上传，无需提交 `dist`。

## 操作与流程

- 加载本地角色资源后进入出战页。底部可切换「园艺装备」和「出战田野」。
- 装备页可切换三把种子武器、三种护符与两双鞋；选择会影响伤害、发射数量、初始技能、生命或移动速度，并保存在本机。
- 战斗时按住任意战场位置，摇杆即出现在落指处。拖动控制方向，长拖动时底座跟随；抬手停止。桌面支持鼠标及 WASD / 方向键。
- 自动瞄准并射击附近敌人，移动中持续开火；停止移动也会开火。碰到灵露获得经验，碰到种子立即获得或强化技能，碰到春露恢复生命。
- 经验满时暂停战斗，弹出三个成长选项。选择后立即生效，已满星技能不再进入常规候选。
- 精英掉落及定时出现的宝匣可碰触开启。展示抽取动画后获得一项技能强化、治疗或灵韵；可点击跳过动画，确认奖励后继续。
- 顶部技能不需要手动施放。喷瓜藤沿途自动落种并生长，炮台净化周围土地；危险区落种的炮台伤害翻倍。爆裂瓜自动解围，冰露花持续减速，荆棘环身攻击，聚灵花扩大拾取范围。
- 左上暂停键或 Esc 暂停；可以继续或保存后返回田野。切后台、页面失焦也会暂停。

## 胜负与保存

- 一局 180 秒，分成六层，每层 30 秒，刷怪压力逐层增加。撑完六层获胜，生命耗尽失败，同帧失败优先。
- 死气从边缘缓慢侵蚀，上限保留中央活动空间。成株净化区与自然安全区取并集，死气内持续扣血。土地机制用于战斗路线与植物收益，不再要求末段必须种植才能存活。
- 对局每两秒自动保存，暂停、页面离开和奖励变更时额外保存。重新进入会询问「放弃本局 / 继续守护」。
- 续玩恢复位置、生命、技能、经验、敌人、植物、道具、计时器、随机状态和未确认的弹窗；已揭晓宝匣不会重新抽奖或再次发奖。
- 结算清除本局存档，将灵韵及最高层数写入本机档案。放弃只清除当前局，装备与已结算灵韵保留。
- 本地存储键为 `bloom-boom.run.v2` 和 `bloom-boom.profile.v2`。旧格式或损坏存档会回退到正常出战页；存储不可用时仍可玩，续玩与档案不保证持久化。没有账号或联网存档。

## 工程约定

- Phaser 3 + TypeScript + Vite。逻辑画布 720×1440，世界 720×1180，画布按视口等比适配，兼顾系统安全边距。
- `src/config/gameConfig.ts` 保存玩法初值、武器、技能和菜单布局。`src/core/GameModel.ts` 独立于渲染实现固定 60Hz 的单局规则。
- `src/systems` 负责输入、土地、成长与保存；`src/ui` 与 `src/scenes` 负责场景、随触摇杆、技能弹窗及复用的战斗飘字。
- `public/assets/granny.svg` 是本项目原创的春耕奶奶矢量插画。游戏内图形以代码绘制，未使用参考游戏的角色、商标或截图作为资产。
- 开发环境显式访问 `/?debug=1` 时提供 `window.__bloom` 测试入口；生产构建不提供此入口。

本版已从早期「三格手动种植、守护驻场、横屏侧栏」方案迭代为「随触移动、自动攻击、拾取成长」；`关于游戏` 下最初草案保留作设计历史。当前不含广告、付费、体力门槛、装备合成或正式音效。自动测试验证规则与交互，真机手感与难度仍需试玩调优。
